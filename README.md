# Novil - 100% Offline AI Coding Assistant

Novil is a fast, local AI coding assistant for Windows. No API keys, no subscriptions, no cloud. 

- **100% Offline:** Runs entirely on your local machine.
- **Optimized for 8GB RAM:** Uses a custom multi-agent pipeline to deliver fast, accurate code generation without melting your laptop.
- **Self-Correcting:** Uses a unique "Reviewer" AI to catch its own bugs before you see them.
- **Vision Support:** Upload screenshots or design mockups and get code back.

- Windows 10/11 (64-bit)
- 8GB RAM minimum
- No internet connection required after downloading local models.
